# v0.4.0 서명 release 검증

2026-11-11 KST, Pleos_Connect_v2.1.0(API 34), 활성 사용자 10에서 사용자 서명 APK를 검증했다.

- APK Signature Scheme v2 검증 성공. 인증서 SHA-256은 v0.3.1의 `b92c3e1968a966880d0f3e7719a0c594395212fdb12a47dc64e2ffa38e377954`와 일치.
- 패키지 `com.example.pleoshellocar`, versionCode 4, versionName 0.4.0.
- 에뮬레이터 앱 삭제 후 기존 v0.3.1 제출 APK 설치 및 v0.4.0 `adb install -r` 업데이트 설치 성공.
- 서명 APK 3,734,970 bytes. 원본과 제출 경로에서 각각 계산한 SHA-256은 모두 `f0faf2afeb610c86a7b6e5c97993157b431e0861ded86ee429b8f8175448496a`다. 에뮬레이터에서 검증한 APK와 커밋 대상 APK의 해시가 같다.
