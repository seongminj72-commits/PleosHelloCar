# 데모 영상 구성표 (v0.4.0 제출용)

- 목표 길이: 약 3분. 공모전 규정에 길이 제한이 있으면 그 값을 우선한다.
- 내레이션 없이 화면과 한글 자막으로 구성하고, 배경음악은 넣지 않는다(저작권 위험 제거).
- 촬영 대상: 서명된 v0.4.0 release APK. 단, 장면 7(실제 TMAP ETA)만 debug 빌드와 로컬 프록시로 촬영한다.
- 원칙: 실제와 데모를 영상에서도 구분한다. 매장·메뉴·결제·주문 상태는 시뮬레이션임을 처음과 끝에 밝힌다.

## 핵심 메시지 (영상이 끝났을 때 남아야 할 것)

1. 도착 시간과 메뉴 준비시간을 맞춰 **언제 주문할지** 알려준다.
2. **실제 차량 기어·속도 신호**로 주행 중 주문 조작을 막는다.
3. 데모용 Mock으로도 **실제 주행 차단을 풀 수 없다** — 호스트 설정에 의존하지 않는 앱 자체 안전 장치.

## 촬영 방법

- 앱 화면: `adb shell screenrecord --bit-rate 8000000 /sdcard/sNN.mp4` (최대 180초) 후 `adb pull`. 장면마다 별도 파일(s02.mp4, s03.mp4 …)로 찍는다.
- 각 클립은 조작 전 2초, 조작 후 2초 정지 화면을 포함한다. 탭은 천천히, 화면 전환 후 1초 기다린다.
- 장면 7은 Virtual Console 조작을 보여주면 설득력이 크다. 가능하면 Mac 화면 녹화(⌘⇧5)로 콘솔과 에뮬레이터를 나란히 찍은 클립(s07-mac.mov)도 함께 만든다. 없으면 편집에서 "Virtual Console: D 기어 · 가속" 자막으로 대체한다.
- 토스트는 몇 초 뒤 사라지므로, 토스트가 보이는 동안 녹화가 계속되게 한다.
- 문구가 화면에서 잘리면 그대로 찍는다. 편집에서 전체 문구를 자막으로 보완한다.
- 화면에 개인정보(실명, 이메일, 계정, 실제 위치 주소)가 나오지 않게 한다. 장면 8의 위치는 에뮬레이터 가상 좌표를 쓴다.

## 편집 메모

- 1920×1080 캔버스 중앙에 에뮬레이터 화면을 배치하고, 하단에 자막 띠(Noto Sans CJK)를 둔다.
- 핵심 문구(장면 3·4·7)는 화면 일부를 확대하고 문구를 굵게 강조한다.
- 장면 7 시작에 "핵심" 표시를 넣는다.
- 출력: H.264 MP4. 파일 크기는 GitHub Release 첨부 한도 안에서 가능한 작게, 메일 직접 첨부를 고려해 25MB 이하를 목표로 한다.
