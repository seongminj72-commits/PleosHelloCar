# TMAP 실제 API 검증

검증일: 2026-11-03. Pleos Connect v2.1.0(API 34), DriveFlow 0.3.0(3), AAOS user 10.

사용자가 TMAP 상품을 활성화하고 로컬 서버 숨김 입력으로 appKey를 제공한 뒤 실제 조회에 성공했다. 로컬 프록시 응답은 HTTP 200, source=TMAP, durationSeconds=520이었다. 입력 위치는 에뮬레이터 서울 테스트 좌표(37.5500,126.9700), 목적지는 가상 매장 A의 테스트 좌표(37.5665,126.9780)다.

앱 로그에서 실제 경로 응답·모의 위치·가상 매장 표시를 확인했고, 메뉴 화면에서 ETA 9분(초 단위 올림), 준비 6분, 여유 1분, 지연 0분에 따른 약 2분 후 주문 추천을 확인했다. 이전 서버 오류 상태에서 새 실제 응답 수신 후 추천이 갱신됐다.

실제 도로 주행이나 실측 GPS 검증은 아니다. NaviHelper 및 실제 결제/POS는 검증 범위에 포함되지 않는다. 기존 문서의 실 API 미검증 설명은 2026-10-30 시점의 기록이며, 본 기록이 실제 TMAP 호출 검증 상태를 갱신한다. 키와 단기 인증 토큰은 기록하지 않았다. TMAP 원본 경로 응답은 보관하지 않는다.
